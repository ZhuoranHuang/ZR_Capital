## 边界

- V4：MU、QQQ，日期同 R-033（2026-07-01～2026-10-21 全部交易日 + 2023-10-02～2026-06-30 周四周五）；负责人：2026-06-09～2026-08-19 D-030 入选 51 段（MU 48、DRAM 2、META 1）。
