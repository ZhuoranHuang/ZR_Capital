## 期权历史（ThetaData Options Standard，`zr/data/thetadata.py`）

验证拉取（2026-10-22，Mac 本地终端，并发 2）：SPY 2026-09-01～09-30（21 个交易日）+ 2026-10-21。

- 规则：每日 DTE ≤ 5 的全部到期日（SPY 每日 3–4 个）、行权价按当日开盘价 ±3% 过滤、call+put；1 分钟 NBBO（末次报价）、1 分钟 OHLC、日度 OI
- 结果：22 天，quotes 3,128,782 行、ohlc 3,099,457 行、oi 7,858 行；**耗时 690 s（平均 31.4 s/天）**，parquet **42 MB（1.91 MB/天）**；失败 0
- 单个到期日 strike=* 的 1 分钟 quote 响应约 22 MB JSON / 5 s（终端本地），是耗时主项
- **全量估算**（2023-10-02～2026-10-21，779 个交易日）：SPY ≈ 6.8 h / 1.5 GB；三标的（MU 带宽 ±8%、行权价更密）≈ **20 h / 4.5 GB** 量级（MU 可能更大）
- Theta 接口事实（本次实测，已写进代码注释）：响应形状 `{"response":[{contract:{...},data:[...]}]}`；当日数据必须指定 expiration；无数据时可能返回 200 + 文本；1m 时间戳 t 的报价 = t 时刻 NBBO
