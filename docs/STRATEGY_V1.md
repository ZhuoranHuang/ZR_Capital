# 策略 v1 定稿（七层）

适用标的：SPY、QQQ、MU、AMD（MU/AMD 是否进入 v0 见 D-009）。频率：1 分钟 bar。工具：单腿买方期权（Long Call / Long Put）。

所有阈值（ε、k、H、delta 目标、P_min、S_max、EV 阈值）都是待测参数，由脚本扫描得出，不在文档里定死（CLAUDE.md 规则 11）。

## 第 1 层：事件生成器

每个检测器输出：`(时间, 标的, 方向, 检测器 ID)`。检测器之间互不排斥；同一分钟可有多个事件。

| ID | 名称 | 做多条件（做空对称） |
|---|---|---|
| E1 | 通道回踩 | MACD DIF > DEA 且 DIF > 0 且 SMA20 中轨斜率 > 0；K 线最低价触及中轨（\|low − mid\| / mid ≤ ε）且收盘回到中轨上方。 |
| E2 | 开盘区间突破 | 突破前 15 / 30 分钟（两个版本分别测）高点。 |
| E3 | VWAP 失而复得 | 价格跌破 VWAP 后重新站上（做空：得而复失）。 |
| E4 | 长均线定向 + 震荡指标顺势交叉 | 120 根均线向上，KDJ 或 RSI 在超卖区向上交叉。退出用"梯形法则"：上涨中跌破前一更高低点即出；只在盈利时加仓。 |
| E5 | CUSUM 过滤器 | 对数价格累计偏移超过阈值 h（López de Prado 2018 第 2 章 2.5.2.1）。 |
| E6 | 布林带挤压扩张 | 带宽处于 20 日低位（分位数待测）后开始扩张，方向取扩张时收盘相对中轨的位置。 |
| E7 | 日内动量 | 收盘前 30 分钟，按当日前段（9:30 至入场前）收益方向入场；只用 1DTE 合约（Gao–Han–Li–Zhou 2018；Baltussen–Da–Lammers–Martens 2021）。 |
| E8 | VWAP 均值回归 | 相对 VWAP 偏离超过 k × ATR 时反向；仅在做市商净 gamma 近似为正时启用（Dim–Eraker–Vilkov 2024）。 |

E1 是负责人手工打法的形式化版本，与其他检测器平等参与评估（D-010）。

## 第 2 层：标签

**正股 triple-barrier**（López de Prado 2018 第 3 章）：
- 上障 +k·σ，下障 −k·σ，时间上限 H ∈ {3, 5, 10, 15, 30} 分钟。
- σ 为滚动实现波动（窗口待测）按 √H 缩放。
- 标签 ∈ {+1, −1, 0}；另记录触障时刻与触障时收益。

**期权扣费后盈亏标签**：按第 5–6 层规则模拟——入场买 ask、出场卖 bid、费用 0.98/张/单边（D-006 费率合计，未验证最新）。需要 NBBO 数据（ThetaData，D-002）。

**事件响应曲线**：每个检测器触发后 1/2/3/5/10/15/30 分钟的正股平均收益与分位数（10/25/50/75/90）。持仓上限由曲线见顶位置决定，是输出不是输入。

## 第 3 层：元标签模型

- LightGBM 二分类，预测 P(扣费后盈利 | 特征)。
- Walk-forward，带 purge + embargo（embargo 长度 ≥ 最大 H）。
- Isotonic 校准。
- 样本按唯一性加权（López de Prado 2018 第 4 章）。

**特征 v0**（全部在事件时刻 t 可得，只用 ≤ t 的数据）：

| 组 | 特征 |
|---|---|
| 趋势 | MACD DIF / DEA / 柱（ATR 归一）；布林 %b、带宽、中轨斜率 |
| 位置 | 相对 VWAP 距离（ATR 归一）；开盘区间位置；到最近高 OI 行权价距离 |
| 收益 | 近 1/5/15/30 分钟收益；隔夜跳空；当日开盘至今收益；昨日及前 5 日同时段收益 |
| 成交 | 1/5/15 分钟成交方向不平衡（Trade 推送 direction 字段）；大单占比；量比（同时段归一） |
| 波动 | 实现波动 5/30 分钟 vs 日度；K 线振幅 / ATR；IV − RV |
| 期权结构 | 做市商净 gamma 近似（GEX，按 OI 计算，**假设**：做市商持有全部 call 多头 / put 空头的对手方）；近端行权价期权成交量变化 |
| 时间 | 距收盘分钟数 |

## 第 4 层：决策

- EV = P · 平均盈利 − (1 − P) · 平均亏损 − 费用 − spread。
- EV > 阈值才交易。
- 仓位 = 分数 Kelly(P)，再取 **持仓上限 = min(单笔风险 5% ÷ 主止损对应的权利金亏损比例, 权益的 15%)**（D-011）。主止损对应的权利金亏损比例 = 正股跌到结构止损位时期权价格的预估跌幅（用 delta / gamma 近似，待测）。
- **分批建仓**（D-011）：首仓 50%；正股创新高且事件状态仍成立时加至 100%，同时止损上移至成本。禁止摊平。
- 到期日按 D-008。
- 时间不是过滤条件（D-011）：除券商规则（D-001）外，时段只作为第 3 层特征，不在决策层设时段门槛。
- 风险阈值评审：实盘 30 笔后扣费后期望为正，再评审是否把单笔 / 单周上限提高到 8% / 20%。

## 第 5 层：合约与执行

- delta 目标 ∈ {0.4, 0.5, 0.6, 0.7, 0.8}，参数。
- 权利金 ≥ P_min（初值 1.0）。
- spread / mid ≤ S_max。
- 入场：ask 限价；2 秒未成交改 ask + 1 tick，最多 2 次。
- 止损出场：bid − k tick。
- 全部经 `zr/execution` OMS；实盘需 `ZR_LIVE=1` + `--live`。

## 第 6 层：退出

优先级从高到低；1 是主止损，2 只是最后防线（D-011）。

1. **主止损 = 正股结构止损**：跌破中轨 k × ATR，或跌破前一更高低点。加仓后止损上移至成本。
2. 最后防线：权利金 −30%，仅在流动性枯竭（报价消失、spread 超限导致无法按结构止损成交）时触发。
3. 时间止损：由事件响应曲线定，是待测参数不是过滤条件。
4. 止盈减半。
5. 券商规则清仓（D-001）：0DTE 10:45 ET 前、所有仓位 15:50 ET 前。
6. 异常撤退：报价消失或 spread 超限。

## 第 7 层：评估

- 假设先登记 `docs/RESEARCH_LOG.md` 再运行。
- Walk-forward；Deflated Sharpe（Bailey–López de Prado 2014）。
- 分层：时段 / 波动 / 标的 / DTE。
- 对照组：同一事件在正股上的 H 分钟收益（剥离期权层影响）。
- W2 首个交付物："事件 × 标签"表 + 事件响应曲线。
